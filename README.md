# FitLog — Workout Library & Gym Companion

FitLog is a premium, dark-themed gym companion and workout library application designed to help athletes organize their training regimens, browse comprehensive exercise cards, and log sets with absolute ease.

## Technologies Used

* Next.js (App Router Architecture)
* React 19 (Hooks & State Management)
* Tailwind CSS (Utility-First Styling Engine)
* React Context API (Global State Engine)
* Custom Scalable Vector Graphics (SVG Component Icons)

## 5 Key Features

* Real-Time Smart Sorting: Automatically re-sorts the live exercise cards on the home screen dynamically based on Duration, Calories Burned, or User Rating without any lag or page refresh.
* Interactive State Training Planner: Load individual lifts directly into "Today's Plan" or append them to the "Saved Lifts" dashboard repository smoothly.
* Live Counter Summary Tracker: Instantly aggregates and displays the exact total numbers for active exercises, estimated minutes, and cumulative burned calories.
* Robust Duplication Prevention System: Built-in validation architecture that detects duplicate items and triggers custom error toast alerts like "Already in your plan" with sharp error icons.
* Dual Floating Sticky Navigation: Engineered layout that anchors a fixed primary menu at the top and a sticky descriptive footer system at the absolute bottom during extensive scrolling.
